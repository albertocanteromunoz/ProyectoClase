# Sitio Web de un centro de FP
---
Este sitio web es de prueba y se usará en clase de Desarrollo de Interfaces Web. 
Consiste en un sitio web para un centro formativo de FP.

## Tecnologías 
- Frontend
    - HTML5 (moderno)
    - CSS5
    - Vanilla JavaScript
- Backend
    - Node.js
    - Express 4.22.3
    - Plantillas EJS

## Arquitectura
- Todo en una única página index, dividido por secciones. 

## Convenciones del lenguaje 
- Usa ingles para las variables y funciones.

## Limitaciones
- No usar grid.
